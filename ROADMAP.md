# Matra roadmap

Principle: **Matra is free, with no plans or tiers.** Every capability that Grammarly sells in its Pro or Enterprise plans ships here at no cost.

## v0.1 — foundation ✅
- [x] Real-time checking in four categories, English + Bangla + Banglish
- [x] Score and tone detection
- [x] Writing goals, set per document
- [x] Rewrite (7 styles + custom), Banglish → Bangla, translation
- [x] Write with AI (compose from a prompt)
- [x] Statistics and readability
- [x] Local documents, autosave
- [x] Keychain key storage, auto-update from GitHub Releases

## v0.2 — the "Pro" features, free
- [ ] Full-sentence rewrites offered as suggestions inside the review list
- [ ] Plagiarism check (web sources with links)
- [ ] AI-text detector with highlighted passages
- [ ] Citation finder + APA / MLA / Chicago generator
- [ ] Personal dictionary (add word, ignore everywhere)
- [ ] Style guide: your own rules ("write email, not e-mail")
- [ ] Snippets: saved text you insert with a shortcut
- [ ] Brand tones: a saved voice profile applied to checks

## v0.3 — agents
- [ ] Reader reactions: how a chosen reader will receive the text
- [ ] AI grader: score against a rubric or assignment brief
- [ ] Proofread whole document in one pass with a change summary
- [ ] Paraphraser with strength control
- [ ] Live fact-check with sources

## v0.4 — everywhere you write (the Grammarly desktop experience)
- [ ] Menu-bar app + global shortcut: check the selected text in any app
- [ ] Floating widget beside text fields (macOS Accessibility API)
- [ ] Import / export .docx, .txt, .md, PDF
- [ ] Weekly insights: words written, most common mistakes, streaks

## v0.5 — futuristic
- [ ] Voice to polished text (English and Bangla dictation)
- [ ] Screenshot / image → text (OCR) → corrections
- [ ] Voice DNA: learn the user's style and write like them
- [ ] Writing coach mode: explain rules, quizzes, progress
- [ ] Offline mode with an on-device model for basic checks
- [ ] Authorship report: what was typed, pasted and AI-written
- [ ] Emotion radar: warn before sending a message that sounds angry
